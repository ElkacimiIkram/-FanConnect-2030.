12. INTELLIGENCE ARTIFICIELLE
================================================================================
Titre : Prédire l'affluence, recommander le lieu.

Modèle
  Algorithme   Random Forest (scikit-learn)
  Service      FastAPI / Python
  Features     occupation courante, historique, horizon avant kickoff,
               fraîcheur du report owner (15 min)

Sorties
  Prédictions à 1 h, 2 h et coup d'envoi
  Niveau de risque : LOW / MEDIUM / HIGH
  Recommandation textuelle

Recommandation de lieux
  Rayon progressif 5 → 10 → 20 km jusqu'à au moins 3 résultats
  Score distance × occupation
  Codes métier (ex. CLOSEST_LOW_CROWD)

FanBot
  Assistant d'intentions : match, café, réservation
  Fallback déterministe si l'API LLM est indisponible

OccupancyEngine (côté Java)
  Mélange report owner (vérité terrain si < 15 min)
  + signaux de réservation (check-in, confirmés, pending)
  Walk-ins pris en compte via le report owner

Honnêteté scientifique
  Entraînement sur données synthétiques + signaux métier
  Pas de saison CDM réelle à apprendre
  Fallback déterministe si le service Python est down

QUESTIONS PROBABLES DU JURY (AIDE-MÉMOIRE)
================================================================================
Q  Stockez-vous les cartes bancaires ?
R  Non. Stripe PCI-DSS, PaymentIntent côté serveur, mode test.

Q  Pourquoi FastAPI à part et pas le ML dans Spring ?
R  Python / scikit-learn, cycle d'entraînement indépendant,
   l'API Java reste le point d'entrée.

Q  L'IA est-elle fiable sans données CDM réelles ?
R  Non au sens production. Random Forest + signaux métier + fallback.
   À recalibrer avec des données réelles (MAE).

Q  Comment est calculée l'occupation ?
R  OccupancyEngine : report owner frais (15 min) = vérité terrain
   (walk-ins inclus). Sinon estimation à partir des réservations
   (check-in + confirmés × 0,85 + pending × 0,60).

Q  Comment isolez-vous les 3 rôles ?
R  Routes React protégées (FanRoute / OwnerRoute / AdminRoute)
   + Spring Security (rôles sur les endpoints).

Q  Pourquoi 5 puis 10 puis 20 km ?
R  Un rayon fixe de 5 km peut vider la liste. Expansion jusqu'à
   au moins 3 établissements.

Q  Qu'est-ce qui est hors périmètre et pourquoi ?
R  Mobile natif, Stripe live, billets de stade : 4 mois, livrable
   démontrable, stack open source / freemium.
